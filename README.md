# Ember VFX Studio

A beginner-friendly browser particle creator with six live presets, plain-language controls, pause and restart, local project saving, validated JSON import/export, and PNG capture.

Run `npm start` and open http://127.0.0.1:4173. Run `npm run check` to check JavaScript syntax.

The renderer previews 2D effects. Ember JSON files are editable project settings, not Unreal Niagara assets. A custom Unreal integration would be required for engine-native export. Projects are stored in the browser on the current device; export JSON to keep a portable copy.
